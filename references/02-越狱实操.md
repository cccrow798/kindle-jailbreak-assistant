# 02 · 越狱实操

以 **WinterBreak2** 为主线（浏览器触发类方法的操作结构基本一致，其他方法把"触发地址"换掉即可）。
另附 Sanctuary / SpringBreak 的差异点，以及持久化与热修复的处理规则。

---

## 一、越狱前

| 项 | 要求 |
|----|------|
| 电量 | ≥ 50% |
| 数据线 | 全程不要拔（触发阶段之后的等待期内） |
| Wi-Fi | 已连接且能上网（浏览器方法必须有网） |
| 备份 | `documents/` 已复制到电脑 |
| 隐藏文件 | Windows 资源管理器开启「显示隐藏项目」 |
| 根目录残留 | **删除** `update*.bin`、`update.bin.tmp.partial` |

> **为什么必须清 `.bin`**：自动更新一旦装上，会把你正要利用的那个固件版本顶掉，机会直接消失。这一步不能省。

---

## 二、WinterBreak2 逐步操作

### 1. 投放越狱包

1. 解压 `wb2.zip` → 得到 `winterbreak2` 文件夹
2. 把**整个文件夹**拷到 Kindle 根目录 → 最终路径为 `F:\winterbreak2\`

### 2. 触发

3. 安全弹出 Kindle，**拔掉数据线**
4. 确认 Kindle 已连上 Wi-Fi
5. 打开 Kindle 上的「**体验版网页浏览器**」
   - 路径：主页右上角菜单 → 体验版网页浏览器
   - 旧固件可能叫「Experimental Browser」，或藏在 设置 → 设备选项 → 高级选项 下
6. 地址栏输入：`https://penguins184.xyz/wb2`
7. 页面加载后点「**Jailbreak**」按钮，弹窗确认后即开始执行

### 3. 等待（屏幕上会依次出现）

| 阶段 | 屏幕提示 |
|------|----------|
| 启动 | `Powered by jb.sh - created by Hackerdude`、版本号（如 `v1.3.7`）、`J:1:0:0:kindlepw2` |
| 停更新 | `Stopping OTA` |
| 装组件 | `Setting KMC permissions` → `Establishing Gandalf links` → `Done` |
| 重启界面 | 大字 `Restarting GUI` / `Please Wait...` |

> ⚠️ 期间**弹出「应用程序错误」对话框是正常的**，提示里通常自带一句 `Error dialog is fine — Just press close and keep waiting!`。点关闭继续等即可。
> 系统界面自动重启的过程**看起来像卡住**，也属正常。

### 4. 收尾

8. 完成后拔线，**删除根目录所有 `update*.bin` / `update.bin.tmp.partial`**
9. 越狱时用于"填充存储"的临时文件可以删掉了
10. 系统更新此时已被**自动屏蔽**（WinterBreak2 自带这步）

## 三、如何确认越狱成功

**设备上的三个硬指标**：

| 检查项 | 期望 |
|--------|------|
| 图书馆里出现 **JAILBROKEN** 这本书 | 最直观；打开显示 "You are jailbroken!"（对应 `F:\documents\JAILBROKEN.txt`） |
| 根目录出现 **`libkh`** 文件夹 | 越狱核心组件已就位（如 `F:\libkh\bin\fbink`） |
| 搜索框输入 **`;log`** 有输出 | `;log` 家族命令可用 → 越狱生效 |

**电脑侧核对**（用 `scripts/detect_kindle.py` 一次跑完）：

```
F:\documents\JAILBROKEN.txt      存在
F:\documents\JAILBROKEN.sdr\     存在（已被索引）
F:\libkh\bin\fbink               存在
F:\apps\tech.hackerdude.winterbreak\ + F:\mesquito\    WinterBreak2 运行环境
```

**稳定性复验**：**重启一次 Kindle**，JAILBROKEN 仍在、`;log` / `;kpm` 仍有反应 → 持久化生效。

## 四、持久化与热修复（Hotfix）

### 谁需要手动打热修复

| 情况 | 是否需要手动跑 hotfix |
|------|----------------------|
| WinterBreak2 / SpringBreak / Sanctuary | **不需要**——官方明说热修复已替你装好（"The hotfix has already been installed for you"） |
| 其他方法（官方向导未标注自动安装的） | 需要，按下节操作 |

### 手动打热修复的步骤

1. 把 `Update_hotfix_universal_<版本>.bin` 拷到 Kindle **根目录**
2. 安全弹出、拔线
3. Kindle 上：设置 → 右上角菜单 → **更新您的 Kindle**
4. 完成后运行出现的 **Run Hotfix** 小册子

### 什么时候需要"补打"

**只有**当重启后发现 `;kpm` / `;log` 失效，才需要把 `.bin` 拷回根目录重跑一次。
平时**不要**在根目录留 `.bin`（会触发系统更新流程）。

## 五、其他触发方法的差异

| 方法 | 差异点 |
|------|--------|
| **Sanctuary** | 装包前先跑兼容性自检（`sanctuary.skyvincent.com/scroll`，页面会用两个滚动条示例告诉你浏览器 build 是否匹配）；自检不过说明浏览器版本不对，需换方法或换固件；支持未注册/黑名单设备 |
| **SpringBreak** | 触发端在**电脑**：下载后运行 `springbreak.exe`（Windows）/ `springbreak-linux` / `springbreak-darwin`，选择挂载的 Kindle → 工具会自己创建填充文件 → 按提示在 Kindle 上短暂开 Wi-Fi 打开商店 → 出现越狱字样后重连电脑跑工具的 cleanup；热修复预装、无需重命名 OTA 二进制 |
| **Véra** | 见官方向导，走的是与固件版本绑定的触发流程 |

---

## 六、这一阶段的禁止动作

| 禁止 | 原因 |
|------|------|
| 恢复出厂设置 | 越狱失效 + 书库清空 |
| 删除 `libkh` / `kmc` / `apps` / `mesquito` | 越狱与包管理器直接失效 |
| 合并/移动 `winterbreak2` 文件夹内容 | 触发页按固定路径找文件 |
| 假装"点不动就是失败"而反复重启 | 表现为卡住往往就是在写盘，先等够时间 |
| 在触发过程中接通自动更新 | 会把可利用的固件顶掉 |
