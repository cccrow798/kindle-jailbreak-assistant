# 07 · 风险与合规

**动手前必须把本文件的内容如实告知用户，并取得明确同意。**
不要为了"让用户高兴"而淡化风险。

---

## 一、必须向用户告知的六件事

### 1. 有变砖风险（低，但非零）

越狱通过漏洞获取系统权限，**理论上存在把设备刷成无法启动的可能**。实际情况：

- 主流方法（WinterBreak2 / Sanctuary 等）经过大量用户验证，失败率很低
- 失败多发生在**中途断电、拔线、卡住时强行复位**之后
- 缓解：电量 ≥ 50%、全程不拔线、卡住时先等够时间再用 40 秒强制重启

### 2. 可能失去官方保修

越狱改动了系统分区内容。部分地区的官方售后可能因此拒保。
（在用户自有设备上安装第三方软件，多地法律并不禁止，但厂商的保修政策可以自行规定。）

### 3. 系统更新会被屏蔽——这是有意为之

越狱会自动屏蔽 OTA 更新。**后果**：拿不到官方安全修复；且**不要手动去装新固件**，升级会覆盖越狱。

### 4. 恢复出厂设置 = 越狱失效 + 书库清空

反复强调。这条是最常见的"手滑事故"。

### 5. 第三方插件不享受任何保证

微信读书（觅阅）等是社区插件，接口依赖对方服务，**可能随时失效**；使用须自行遵守对应平台的用户协议。
插件代码来自社区，安装前应说明来源，不要装来路不明的包。

### 6. 数据不可逆

设备端**没有回收站**。删书、删 `.sdr`（阅读位置/标注/X-Ray）都是永久性的。
→ 动手前先把 `documents/` 备份到电脑。

## 二、能力边界：本技能明确不做的事

| 不做 | 原因 |
|------|------|
| **不破解、不绕过、不协助绕过任何 DRM** | 属于规避技术保护措施。遇到 `encryption=2` 或 KFX 一律不转换，只解释原因并说明原生阅读器可读 |
| **不提供、不指引、不暗示任何解密工具或做法** | 同上 |
| **不刷第三方系统 / 不换内核** | 超出"解锁安装权限"的范围，变砖风险显著上升，且不可回退 |
| **不修改设备序列号、不绕过账号与区域限制** | 涉及身份伪造与平台规则 |
| **不替用户接受任何协议** | 账号、插件的协议由用户自行确认 |
| **不在用户未明确同意时删除数据** | 不可逆操作一律先确认 |

## 三、合法性的正确表述

给用户的口径应当是：

- 在**自己拥有**的设备上安装第三方软件、解除厂商的软件安装限制，在多个法域（含美国 DMCA 的越狱豁免条款、欧盟相关判例）是**被容忍甚至被明确允许**的行为
- 但**各地法律不同**，用户需自行确认所在地区的适用规定
- **越狱 ≠ 可以获取盗版内容**。越狱只解除设备限制，不改变内容的版权状态
- 购买自亚马逊的电子书受 DRM 保护，**越狱不会也不需要解除它**——这些书在原生阅读器里照常可读

**不要**向用户做法律结论式的断言（如"这在任何情况下都合法"）。表述为"通常被允许，但请遵守当地法律与平台协议"。

## 四、越狱后性能的如实回答

用户常问"越狱会不会让设备变慢"。**如实回答**：

- **越狱本身不改变原生系统性能**。原 Kindle 界面照常运行，越狱只是额外装了组件，不开就不占资源
- **KOReader 作为独立应用**，只有启动它才占用资源；退出后不影响原生阅读器
- **真正会感觉到慢的场景**是 KOReader 内部的原因：**词典启用过多**导致查词阻塞主线程（可修）、首次打开书籍生成缓存（一次性）、首进文件浏览器提取封面（一次性）
- **文件数量不是性能因素**——打开一本书只加载那一本

不要笼统答"不会变慢"，也不要顺着用户的假设答"我给你删点书就好了"。

## 六、出问题时的止损原则

1. **先停手**，不要再叠加操作
2. **先备份现状**（把当前 `documents/`、`koreader/`、配置复制出来）
3. **保留证据**：`crash.log`、屏幕提示文字（拍照）
4. **优先尝试最轻的修复**：强制重启 → 重跑热修复 → 重装包
5. 只有在以上都无效时，才讨论更重的方案，并**明确告知后果**
